# Website Resmi Yayasan Inovasi Hijau Lestari

Website profil lembaga nirlaba (*non-profit organization*) **Yayasan Inovasi Hijau Lestari** (Green Sustainable Innovation Foundation) yang modern, profesional, responsif, dan bernuansa ramah lingkungan (*eco-friendly*).

🔗 **Live Website (GitHub Pages):** [https://novizarnazir25-cyber.github.io/yayasan-inovasi-hijau-lestari/](https://novizarnazir25-cyber.github.io/yayasan-inovasi-hijau-lestari/)  
📦 **GitHub Repository:** [https://github.com/novizarnazir25-cyber/yayasan-inovasi-hijau-lestari](https://github.com/novizarnazir25-cyber/yayasan-inovasi-hijau-lestari)

---

## 🌟 Fitur & Keunggulan Website

### 1. Desain Visual & Estetika Hijau (*Design System*)
- **Palet Warna Alami & Berkelanjutan:**
  - *Forest Green* (`#1b4332`, `#2d6a4f`) sebagai warna primer melambangkan pertumbuhan alam dan keberlanjutan.
  - *Earthy Terracotta* (`#b85d3b`, `#8c3e20`) sebagai warna sekunder melambangkan tanah subur dan kehangatan kemanusiaan petani.
  - *Soft Cream / Warm Sand* (`#fbf9f5`, `#f4f0ea`) sebagai latar belakang hangat yang nyaman di mata.
  - *Dark Charcoal* (`#1c2520`) untuk kontras tipografi yang optimal.
- **Tipografi Modern:** Menggunakan perpaduan *Plus Jakarta Sans* untuk *display/headings* dan *Inter* untuk teks tubuh (*body copy*).
- **Aset Visual Terkurasi:** Citra resolusi tinggi petani Indonesia, lanskap persawahan lestari, pembuatan kompos/pupuk hayati, dan sertifikasi produk.
- **Ikonografi Vektor:** Didukung oleh Font Awesome 6 dan Lucide Icons.

## 📂 Struktur Halaman Lengkap Sesuai Blueprint

1. **Header & Navigasi:**
   - Logo resmi Yayasan Inovasi Hijau Lestari dengan lambang tunas daun inovatif.
   - Menu navigasi cepat: Beranda, Tentang Kami, Program & Layanan, Aktivitas Nyata, Berita/Artikel, Kontak.
   - Tombol CTA utama: **"Dukung Petani"** dengan akses modal donasi & kemitraan langsung.
   - *Mobile Off-Canvas Navigation Drawer* responsif dengan *backdrop blur*.

2. **Hero Section (Beranda):**
   - Headline: *"Mewujudkan Kedaulatan Pangan & Kesejahteraan Petani Berkelanjutan"*.
   - Sub-headline penguat visi pertanian Indonesia mandiri dan lestari.
   - Tombol ganda: *"Jelajahi Program Kami"* & *"Hubungi Kami"*.
   - Kartu melayang interaktif (*floating impact card*) dengan sorotan fokus gerakan hijau.

3. **Tentang Kami (About Us):**
   - Profil Singkat & Filosofi Gerakan Yayasan.
   - **Visi Resmi:** *"Menjadi lembaga sosial terdepan dalam mewujudkan kedaulatan pangan dan kesejahteraan petani melalui penerapan pertanian berkelanjutan yang berwawasan lingkungan."*
   - **4 Pilar Misi Yayasan:**
     1. Inovasi Teknologi Terjangkau
     2. Kapasitas & Edukasi Petani
     3. Jejaring Pasar yang Adil
     4. Advokasi & Pelestarian Alam
   - **Maksud & Tujuan Yayasan:**
     - Sosialisasi penerapan pengembangan pertanian berkelanjutan.
     - Pendampingan sertifikasi produk pertanian berkelanjutan.
     - Pendampingan pendaftaran izin edar pupuk organik, pupuk hayati, dan pembenah tanah.
     - Pendampingan Pola Kerjasama Demplot.
     - Kegiatan lainnya berkaitan dengan implementasi pertanian berkelanjutan.

4. **Program & Layanan (Services):**
   - Grid kartu interaktif dengan efek *hover lift* & ikon:
     1. *Sosialisasi Pertanian Berkelanjutan*
     2. *Pendampingan Sertifikasi (Organik SNI, Halal, PSAT)*
     3. *Legalitas & Izin Edar Pupuk Hayati & Organik*
     4. *Kerjasama Demplot (Demonstration Plot)*
     5. *Konsultasi & Implementasi Solusi Agroekologi Sirkular*

5. **Aktivitas Nyata & Portofolio Dampak:**
   - Navigasi tab filter dinamis: *Semua Aktivitas*, *Sekolah Lapang*, *Pupuk Hayati (PHC)*, *Pengendalian Hama (PHT)*, *Sertifikasi & Pasar CSA*.
   - Modal popup detail aktivitas dengan foto, metodologi, dan capaian terukur.

6. **Dampak Nyata (Animated Impact Counters) & Ajakan Kolaborasi:**
   - Animasi angka interaktif berbasis *Intersection Observer*:
     - **4.850+** Petani Terbina
     - **120+** Kelompok Tani Mitra
     - **85+** Produk Tersertifikasi & Izin Edar
     - **42+** Desa Binaan Lestari
   - Modal Interaktif *"Dukung Petani & Kolaborasi"*:
     - Tab 1: Donasi Sarana Tani (Pilihan nominal cepat & QRIS/Transfer)
     - Tab 2: Kemitraan CSR & Korporasi
     - Tab 3: Pendaftaran Sahabat Tani / Relawan

7. **Berita, Edukasi & Artikel Tani:**
   - 3 artikel edukasi: Resep pupuk hayati cair mandiri, panduan sertifikasi organik SNI kelompok tani, dan kisah sukses demplot hasil panen naik 28%.

8. **Pertanyaan Umum (FAQ Accordion):**
   - Jawaban tuntas mengenai cara pendaftaran sekolah lapang, pengurusan izin edar, mekanisme CSR, dan pola demplot.

9. **Kontak & Footer:**
   - Formulir pesan terintegrasi dengan validasi *real-time* & *toast alert*.
   - Informasi lengkap: Alamat kantor resmi di Bogor, email institusi, hotline WhatsApp, jam layanan, dan simulasi peta balai riset.
   - Footer komprehensif berlatar Forest Green lengkap dengan navigasi cepat, nawala (*newsletter*), dan hak cipta: `Copyright © 2026 Yayasan Inovasi Hijau Lestari`.

## 💻 Cara Menjalankan Website

### Membuka Langsung di Peramban (Tanpa Instalasi)
Anda dapat langsung membuka file `index.html` dengan mengklik dua kali (*double click*) pada file:
```
c:\Users\ASUS\Desktop\BAHAN PPT\yayasan-inovasi-hijau-lestari\index.html
```

### Menjalankan via Local Web Server (Opsional)
Jika ingin menjalankan server lokal menggunakan Node.js / NPX:
```bash
cd "c:\Users\ASUS\Desktop\BAHAN PPT\yayasan-inovasi-hijau-lestari"
npx serve .
```
Lalu buka alamat yang tertera (biasanya `http://localhost:3000`).

## 🚀 Panduan Publikasi ke Internet (*Deployment*)
Website ini dirancang statis dan mandiri (*standalone HTML5/CSS/JS*), sehingga dapat di-*deploy* dalam hitungan menit ke berbagai platform gratis:
- **Vercel / Netlify:** Cukup tarik (*drag & drop*) folder `yayasan-inovasi-hijau-lestari` ke dashboard Vercel atau Netlify.
- **GitHub Pages:** Unggah folder ke repository GitHub dan aktifkan GitHub Pages dari menu *Settings > Pages*.
- **cPanel / Web Hosting Tradisional:** Unggah seluruh isi folder ke direktori `public_html`.
